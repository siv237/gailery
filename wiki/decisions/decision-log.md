# Лог архитектурных решений

Обоснование ключевых архитектурных решений Gailery. Новые решения добавлять сверху.

## D-2026-07-31: Живые семечки (catalog)
**Решение:** семечка альбома типа `catalog` — живая ссылка (`root_id|path`), а не снимок
содержимого. Фото НЕ копируются в `album_photos`; состав альбома вычисляется в момент
чтения через `get_catalog_photo_ids()` (canonical, deleted=0, ingested=1, рекурсивно).
**Обоснование:** добавление каталога в альбом должно отражать изменения каталога автоматически:
pipeline (существующая индексация) поддерживает `catalog_files` актуальным — альбом следует
за ним без отдельного watcher'а. Резолвер встроен в `get_album_photos()` — единая точка
для всех читателей (основной и share API).
**Дальше (план соответствия):** тот же динамический принцип — для всех групповых семечек
(persona, album); материализованными остаются только photo-семечки и будущие
exclude-семечки (поштучное исключение фото из динамического состава).
**Связь:** [Альбомы](../entities/albums.md).

## D-2026-07-09: Слой LLM Wiki
**Решение:** добавить каталог `wiki/` — LLM-поддерживаемую вики поверх проекта (паттерн LLM Wiki).
**Обоснование:** существующие доки (AGENTS.md, PIPELINE.md, MODULES.md) статичны и дублируют код.
Вики — накапливаемый синтез: глоссарий, концепты, troubleshooting, лог решений, который агент
держит в актуальном состоянии без рутины со стороны человека.
**Связь:** `wiki/AGENTS.md` (схема), `wiki/index.md`, `wiki/log.md`.

## D-2024: Идентификация через content_hash
**Решение:** файлы идентифицируются по `content_hash` (xxh128), а не по путям.
**Обоснование:** пути меняются (маунты, переезды, относительный/абсолютный формат). content_hash
надёжен. Все привязки faces/embeddings/описаний — через content_hash.
**Связь:** [Глоссарий](../glossary.md).

## D-2024: Двухконтурная архитектура GPU
**Решение:** GPU-задачи в режимах local/ollama, переключаемых `OLLAMA_MODE`.
**Обоснование:** автономность по умолчанию + возможность использовать внешний/сетевой Ollama.
**Связь:** [Двухконтурная архитектура](../concepts/dual-circuit.md).

## D-2024: Watchdog следит только за pipeline
**Решение:** пёс отвечает ТОЛЬКО за бесконечный цикл pipeline.py; спит при `no_restart`.
**Обоснование:** индивидуальные шаги управляются вручную из UI, пёс не должен их трогать или
просыпаться от них.
**Связь:** [GPU arbitration](../concepts/gpu-arbitration.md).
