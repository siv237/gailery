## [2026-07-31] ingest | Коррекция времени: фикс схлопывания суток применён
Идеологический баг исправлен: `_exif_time()` (секунды суток) заменена на `_exif_dt()`
(полный datetime EXIF) в camera_group и apply_time_shift. Якорь стартует со своей
эффективной позиции (manual_date или date); позиции кадров всегда пересчитываются от
якоря по полным EXIF-разницам (старые manual_date кадров игнорируются — повторная
коррекция работает от исходного EXIF-расклада). Проверено на «Пхукете»: 704 кадра SONY
разложились по 7 дням, количества по дням совпали с исходной съёмкой, расхождение у всех
кадров единое +2882 мин. 146 тестов API зелёные. Страница: entities/albums.md.

## [2026-07-31] ingest | UTC скорректированных кадров — по привязке альбома, не браузера
Разнобой при просмотре альбома после коррекции времени: date_utc считался от пояса
БРАУЗЕРА (+10), а manual_date задаётся на шкале времени сцены (+07 Пхукет) → кадры
разъезжались с телефоном на 3 часа (змеи 19 июля: SONY 00:09 UTC vs телефон 03:19 UTC).
Фикс (по уточнению пользователя): date_utc по ближайшей UTC-привязке альбома
(`_album_utc_anchors` — кадры с EXIF OffsetTime, manual_date IS NULL):
utc = utc_соседа + (manual − scene_соседа); ближайший сосед покрывает несколько поясов
(перелёт). Fallback — tz браузера. Новый endpoint POST /{id}/repair_manual_utc для
ремонта старых данных: Пхукет отремонтирован (704/704), 3 других альбома оказались
верными (там пояс сцены = поясу браузера). 5 новых тестов (TestAlbumManualDatesUTC),
151 тест API зелёный. Страница: entities/albums.md.

## [2026-07-31] ingest | Даты видео без EXIF: регистратор YYMMDD-HHMMSS + фикс регистра .MOV
Видео видеорегистратора (27 шт, Пхукет) имели дату 2026-07-01 00:00:00: файлы без
creation_time, имя EMER260712-130023 (YYMMDD-HHMMSS) не распознавалось, дата бралась
из папки 2026/07 с днём=1. Плюс баг: `.MOV` заглавными шло по ветке фото (endswith без
lower). Доработан resolve_date по ТЗ пользователя: папка — только полная дата (Y/M/D),
время — из имени файла; папка неполная → дата+время из имени; иначе mtime. Видео
переобработаны: даты/время из имён, date_tz='local', duration, codec; в альбоме встали
на свои дни рядом с телефоном. tests/test_exif.py (17 тестов), 283 теста зелёные.
Грабля №5 в guides/troubleshooting.md.
